# Linux client ingredients

The existing `scripts/native_library.py` entrypoint provides `control-client`,
`check-client`, `build-client`, `phase-client` and `verify-client`. Python must
run with `-I -B` as an unprivileged Linux builder on AArch64 or x86-64. The
runtime recipe builds MIT Kerberos. A distinct test-only SASL bootstrap breaks
the LDAP/GSSAPI build dependency cycle without admitting reduced runtime
capabilities. Direct invocation refuses unsafe interpreter mode before application
imports; short help remains read-only. Final SASL, LDAP, PostgreSQL, coherent
wheel assembly, relocation, ABI and service qualification remain separate work.

Completion readers rederive recipe metadata from the original captured streams.
Validated metadata cannot shadow process, launch or capture fields. Every other
terminal field must match the original supervisor record, and metadata values
must match the recipe's assessment. Artifact identities must remain unchanged
throughout readback.
