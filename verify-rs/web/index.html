Verify an evidence bundle

The verifier runs in your browser. A bundle you choose is read locally and is never uploaded; verifying it makes no bundle-related network request. This is a second, separately implemented verifier (Rust → WASM); it agrees with the Python verifier on the shared golden suite.

Bound: it validates the checkpoint and key history presented here, not whether that is the latest history. A terminal key-history event omitted with a matching JWKS is undetectable offline; compare an independently obtained later checkpoint or key-log high-water.
