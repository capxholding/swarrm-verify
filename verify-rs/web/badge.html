Evidence verification link

Put this link next to an evidence-bundle download. It opens a local E1 verifier; the link itself makes no claim about an agent, an action, capture completeness, or a bundle. It is a static inline-SVG anchor with no callback to Swarrm.

Copy-paste embed

Paste anywhere. The verifier deliberately does not fetch bundle URLs from a badge link: visitors download the bundle they intend to inspect and choose it locally, so a query string cannot make their browser contact an arbitrary host.
